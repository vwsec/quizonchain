🏁 Bottom Line
Groq wins on: Requests per minute (90 vs 5), established stability, multi-key rotation already tested.

Cerebras wins on: Total daily tokens (1M vs 300K — 3.3×), speed (2.6-4× faster), context window (65K vs 8K — 8×), 3 model choices including one Production-grade, single API key management (no rotation complexity), quiz capacity (250 vs 75 per day).

The play: Cerebras as the primary gen provider for sustained volume (1M tokens/day + 65K context). Groq as the burst companion for concurrent traffic (90 RPM). Combined capacity = 4.3× your current limit. For moderate traffic (≤250 quizzes/day), you can run on Cerebras alone and never touch the fallback.
